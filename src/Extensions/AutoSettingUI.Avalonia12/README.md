# AutoSettingUI.Avalonia12

Avalonia 12 build of the AutoSettingUI Avalonia panel. Use this package instead
of `AutoSettingUI.Avalonia` with Avalonia 12. The two packages share the same
assembly and must not be referenced together. Existing namespaces and the
`avares://AutoSettingUI.Avalonia/Themes/Generic.axaml` theme URI are unchanged.

See the [project documentation](https://github.com/StarryXYJ/AutoSettingUI)
for usage.
