# Interface & Model Reference

All types are in the `AutoSettingUI.Core` namespace.

---

## `ISettingDescriptorProvider`

```csharp
namespace AutoSettingUI.Core.Interfaces;

public interface ISettingDescriptorProvider
{
    SettingClassDescriptor? GetDescriptor(Type type);
    SettingClassDescriptor? GetDescriptor(string typeName);
    IReadOnlyList<SettingClassDescriptor> GetAllDescriptors();
    bool HasDescriptor(Type type);
    bool HasDescriptor(string typeName);
}
```

Provides `SettingClassDescriptor` objects for types marked with `[SettingUI]`. Two implementations are available:

| Implementation                        | Location                               | AOT Safe                   |
| ------------------------------------- | -------------------------------------- | -------------------------- |
| `ReflectionSettingDescriptorProvider` | `AutoSettingUI.Core`                   | ❌ Uses `System.Reflection` |
| `GeneratedSettingProvider`            | Generated by `AutoSettingUI.Generator` | ✅ Fully AOT-safe           |

---

## `IPropertyValueAccessor`

```csharp
namespace AutoSettingUI.Core.Interfaces;

public interface IPropertyValueAccessor
{
    object? GetValue(object target, string propertyName);
    void SetValue(object target, string propertyName, object? value);
}
```

Abstracts property get/set operations on target objects. Two implementations:

| Implementation               | Location                               | AOT Safe                      |
| ---------------------------- | -------------------------------------- | ----------------------------- |
| `ReflectionPropertyAccessor` | `AutoSettingUI.Core`                   | ❌ Uses `PropertyInfo`         |
| `GeneratedSettingProvider`   | Generated by `AutoSettingUI.Generator` | ✅ Switch-based, no reflection |

> ℹ️ `GeneratedSettingProvider` implements **both** interfaces, so a single instance can be assigned to both `DescriptorProvider` and `PropertyAccessor`.

## `SettingClassDescriptor`

Immutable descriptor for a class marked with `[SettingUI]`.

| Property                        | Type                                | Description                               |
| ------------------------------- | ----------------------------------- | ----------------------------------------- |
| `TypeName`                      | `string`                            | Fully-qualified type name.                |
| `DisplayName`                   | `string`                            | Short class name used as fallback header. |
| `MainHeader`                    | `string?`                           | Override header from `[MainHeader]`.      |
| `Category`                      | `string?`                           | Navigation category.                      |
| `Order`                         | `int`                               | Navigation sort order.                    |
| `Properties`                    | `IReadOnlyList<PropertyDescriptor>` | Top-level (non-sub-sectioned) properties. |
| `SubSections`                   | `IReadOnlyList<SubSectionInfo>`     | Grouped sub-sections.                     |
| `DefaultControlFactoryTypeName` | `string?`                           | AOT-safe class-level factory type name.   |
| `DefaultFactoryMethod`          | `string?`                           | Static factory method name.               |

---

## `PropertyDescriptor`

Immutable descriptor for a single property.

| Property                       | Type      | Description                                |
| ------------------------------ | --------- | ------------------------------------------ |
| `PropertyName`                 | `string`  | C# property name.                          |
| `DisplayName`                  | `string`  | Label rendered next to the control.        |
| `PropertyTypeName`             | `string`  | Full type name (e.g., `System.Boolean`).   |
| `IsEnum`                       | `bool`    | Whether the property is an enum type.      |
| `IsCollection`                 | `bool`    | Whether the property is a collection.      |
| `HasRange`                     | `bool`    | Whether `[Range]` is applied.              |
| `MinValue` / `MaxValue`        | `double`  | Range bounds.                              |
| `ItemsSourceTypeName`          | `string?` | Source type for `[ItemsSource]`.           |
| `ItemsSourcePropertyName`      | `string?` | Member name for `[ItemsSource]`.           |
| `CustomControlBinding`         | `string?` | Control type name from `[ControlBinding]`. |
| `CustomControlBindingProperty` | `string?` | Binding property name.                     |
| `CustomControlFactoryMethod`   | `string?` | Factory method name.                       |

---

## `SubSectionInfo`

Groups a set of `PropertyDescriptor` items under a sub-section title.

| Property     | Type                                | Description               |
| ------------ | ----------------------------------- | ------------------------- |
| `Title`      | `string`                            | Sub-section header.       |
| `Properties` | `IReadOnlyList<PropertyDescriptor>` | Properties in this group. |

---

## `NavigationNode`

ViewModel for the sidebar navigation tree. Contains child nodes for sub-sections.

| Property    | Type                                   | Description                           |
| ----------- | -------------------------------------- | ------------------------------------- |
| `Title`     | `string`                               | Displayed node text.                  |
| `SectionId` | `string`                               | ID tag used to scroll to the section. |
| `Children`  | `ObservableCollection<NavigationNode>` | Child nodes (sub-sections).           |
